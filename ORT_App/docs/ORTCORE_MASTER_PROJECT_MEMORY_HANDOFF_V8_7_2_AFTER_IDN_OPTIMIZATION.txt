1. IDENTITAS DAN VISI PROYEK
-----------------------------
ORT Translation / ORTCore adalah penerjemah dialog game real-time berbasis OCR
untuk pengguna Indonesia. Sistem menangkap area dialog, membaca teks melalui
OCR, membersihkan noise, menerjemahkan ke Bahasa Indonesia, menerapkan lapisan
naturalisasi IDN, lalu menampilkan hasil melalui overlay/WebUI. Proyek juga
mempunyai cache, glossary, speaker/NPC learning, profile game, diagnostic,
runtime repair, dan log evaluasi.

Perangkat utama pengguna:
- Acer Predator Helios Neo PHN16-71
- Intel Core i7-13700HX
- NVIDIA RTX 4050 Laptop GPU 6 GB
- RAM 64 GB
- Windows

Tujuan kualitas:
- terjemahan cepat dan tetap akurat/natural;
- status backend jujur;
- penggunaan GPU/VRAM aman;
- noise OCR dan false speaker tidak mencemari hasil;
- cache membantu dialog stabil tanpa merusak makna;
- seluruh perbaikan dapat dilacak melalui dokumentasi dan tes.

6. KNOWN ISSUES / BATASAN YANG JANGAN DILUPAKAN
------------------------------------------------
- Tiny/blurred numeric OCR pada GFL2 masih merupakan known minor limitation
  setelah numeric ROI fix, kecuali terbukti regresi baru.
- Jangan menciptakan angka yang tidak terbaca; lebih baik tidak lengkap
  daripada salah informasi.
- Cache HIT tidak harus terjadi untuk dialog baru atau progressive text;
  target sehat adalah final dialog/replay identik dapat HIT.
- Jangan benchmark Fast bila applied backend masih Argos Offline.
- V4 berhak memiliki jalur hybrid/online-assist, tetapi hanya dianggap aktif
  bila log applied membuktikannya.
- Speaker/NPC learning harus konservatif; body/narration tidak boleh menjadi
  speaker hanya karena kata pertama.
- GFL dan GFL2 adalah profil terpisah dan tidak boleh dicampur diam-diam.
- Data user tidak ditimpa dalam patch kecil tanpa persetujuan/backup.
