# ORT v9.0 GitHub-ready Restructure Plan

v9.0 tetap direncanakan sebagai ZIP proyek utuh dalam folder baru. Root diminimalkan menjadi launcher pengguna (`Start OCR` dan `Runtime`), sedangkan source, configs, docs, tools, tests, assets, models/runtime, user-data, logs, cache, dan backups ditempatkan pada folder terorganisasi. Migration plan dari v8.x dan master handoff/ledger wajib ikut diwariskan.
