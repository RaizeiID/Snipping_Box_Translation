segment replay, Japanese ASR filtering, translation completeness, UI wiring,
and preservation of R2–R6 behavior.

## Hardware boundary

The build environment does not provide the user's Windows WASAPI device, RTX 4050,
CUDA DLL set, or GFL2 audio. Therefore this report does not claim a live CUDA speedup,
30-minute GFL2 stability run, VRAM coexistence measurement, or Japanese accuracy score.
Those acceptance checks must be completed on the target laptop. GPU mode is designed
to fail visibly when its probe is not satisfied; Hybrid may continue as CPU Guard.
