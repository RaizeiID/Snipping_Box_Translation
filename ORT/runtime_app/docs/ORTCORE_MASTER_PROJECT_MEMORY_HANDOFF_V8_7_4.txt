ORTCORE / ORT TRANSLATION — MASTER PROJECT MEMORY HANDOFF v8.7.4
==================================================================
Tanggal: 26 Mei 2026
Tujuan: memo kedua untuk melanjutkan proyek setelah memory ChatGPT dibersihkan. Baca bersama ZIP proyek/log terbaru; source dan log terbaru tetap sumber kebenaran utama.

A. IDENTITAS PROYEK
ORT Translation adalah penerjemah dialog game real-time berbasis OCR/overlay untuk Bahasa Indonesia, dengan profile GFL2, GFL, WUWA dan CUSTOM; model Normal/Lite/Fast/IDN; cache, diagnostic, speaker identity, dan WebUI. Hardware utama pengguna: Acer Predator Helios Neo PHN16-71, i7-13700HX, RTX 4050 Laptop 6 GB, RAM 64 GB.

B. WORKFLOW WAJIB
Pengguna menguji tiap patch lalu mengirim log/temuan. Seluruh analisis, saran, keputusan, dan keterbatasan menjadi roadmap kumulatif. Rilis minor dikirim sebagai changed-files ZIP terintegrasi dan dipasang lebih dahulu pada clone folder uji. Dokumentasi/memo ini wajib diperbarui di setiap rilis.
