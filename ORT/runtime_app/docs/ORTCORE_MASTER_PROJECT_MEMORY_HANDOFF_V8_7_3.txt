1. IDENTITAS DAN VISI PROYEK
-----------------------------
ORT Translation / ORTCore adalah penerjemah dialog game real-time berbasis OCR
untuk pengguna Indonesia. Sistem menangkap area dialog, membaca teks melalui
OCR, membersihkan noise, menerjemahkan ke Bahasa Indonesia, menerapkan lapisan
naturalisasi IDN, lalu menampilkan hasil melalui overlay/WebUI. Proyek juga
mempunyai cache, glossary, speaker/NPC learning, profile game, diagnostic,
runtime repair, dan log evaluasi.

Perangkat utama pengguna:
- Acer Predator Helios Neo PHN16-71
- Intel Core i7-13700HX
- NVIDIA RTX 4050 Laptop GPU 6 GB
- RAM 64 GB
- Windows

Tujuan kualitas:
- terjemahan cepat dan tetap akurat/natural;
- status backend jujur;
- penggunaan GPU/VRAM aman;
- noise OCR dan false speaker tidak mencemari hasil;
- cache membantu dialog stabil tanpa merusak makna;
- seluruh perbaikan dapat dilacak melalui dokumentasi dan tes.

V8.7.3 LATE UI REQUIREMENT — SIMPLE-ORIGIN ORANGE/MIGRATION BEHAVIOR
---------------------------------------------------------------------
On 26 May 2026, immediately before v8.7.3 packaging, the user specified that names added from the checked `Tampilan Sederhana` workflow must not be lost or require manual retyping when switching to Normal/Detail. Implemented decision: such valid but unsorted entities are stored with simple/unsorted origin, represented as orange selectable action items in the Normal UI, and may be deleted or migrated into the appropriate detailed category. Entities already sorted in Normal are shown in their normal/green category state and are selectable for delete/edit but do not offer simple-origin migration. Migration preserves multi-word entities such as `Alya Kujou`, `URNC Leader`, and `M4 SOPMOD II` as atomic identities.
