# Migration Notes v7.1

1. Ekstrak folder `ORT_Translation_v7_1` ke lokasi baru.
2. Jalankan `Start_ORT_Translation.bat`.
3. Pilih game:
   - GFL2 Exilium: gunakan rekomendasi Balanced.
   - Wuthering Waves: gunakan Safe Game/Lite/Fast jika laptop terasa berat.
4. Tekan Start.
5. Setelah runtime berjalan, cek `Runtime & Tools -> V7.1 Core Bridge Status` atau file `v71_core_status.json`.

## Untuk laptop Acer Predator Helios Neo PHN16-71 / RAM 64GB / RTX 4050 6GB

- GFL2 Exilium: aman di Balanced/Hybrid.
- Wuthering Waves: disarankan CPU + Lite V2 / Lite IDN V2 / Fast, OCR Resolution 50-60%, interval 420-600ms.
- GPU mode tetap bisa dipilih manual, tetapi Safe Game direkomendasikan agar VRAM game tidak direbut OCR.

## Update berikutnya

Setelah paket lengkap v7.1 ini, update berikutnya sebaiknya kembali berbentuk ZIP berisi file yang berubah saja.
