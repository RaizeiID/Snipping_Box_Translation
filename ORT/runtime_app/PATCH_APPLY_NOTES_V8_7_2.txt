ORT Translation v8.7.2 — PATCH APPLY NOTES
============================================
Type: CHANGED-FILES PATCH ONLY
Base required: ORT Translation v8.7 folder with v8.7.1 patch already applied.

HOW TO APPLY
1. Backup your current ORT Translation v8.7.1 folder.
2. Extract ORT_Translation_v8_7_2_CHANGED_FILES_PATCH.zip into the project root.
3. Replace files when prompted.
4. Do not delete your personal logs or NPC/glossary data before review.

DATA SAFETY
- This patch intentionally does not include/overwrite `npc_database.json`, `data_processing_store.json`, `webui_prefs.json`, or `configs/app_state.json`.
- Run `python tools/npc_database_cleanup.py --dry-run` first to review legacy false speakers.
- Apply cleanup without `--dry-run` only after reviewing the proposed migration/removals.
