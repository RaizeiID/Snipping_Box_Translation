ORT Translation v8.3.4 - Fast Final Lock & Auto Preset UX Patch
=====================================================================
Type: final v8.3 tuning / WebUI UX / Fast Lock
Base: v8.3.3
Date: 2026-05-20

Purpose
-------
This is intended as the final v8.3 Fast optimization patch before v8.4. It keeps Fast CT2,
Fast V1/V2/Fast IDN behavior intact while improving WebUI preset memory and protecting
Fast-related code from accidental changes in v8.4.

Implemented
-----------
- Removed the explicit "Simpan Default Model Ini" workflow from the model picker area.
- Added automatic per-model preset memory: changing Mode, Engine, Interval, or OCR now saves
  the selected model's custom default automatically.
- Added a visible orange "• Modification" badge below the selected model when custom defaults
  exist for that model.
- Added a red oval "Reset Default" button that only appears when the selected model has a custom
  modification.
- Reset Default restores the model's built-in defaults and hides the Modification badge.
- Added Fast Lock documentation for v8.4 so future Lite IDN / OCR / Diagnose updates do not
  accidentally alter the Fast CT2 path or Fast V1/V2/Fast IDN tuning.
- Added a Fast lightweight post-processing guard to reduce rare first-use latency spikes from
  heavyweight linguistic post-processing cores in Fast profiles. Fast IDN still uses the lightweight
  Indonesian naturalizer.

Known limitations
-----------------
- This patch locks/tunes Fast, but OCR crop quality still matters. Very wide crops can still produce
  noise such as stray Chinese characters, numbers, and wrong speaker names.
- NPC merge/review UI remains planned for v8.4.
- v8.4 should focus on Lite IDN, Diagnose & Repair Center, OCR preprocessing profiles, and NPC cleanup,
  while respecting docs/FAST_MODEL_LOCK_V8_4.md.
