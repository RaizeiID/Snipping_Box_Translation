ORT Translation v8.3 - Runtime Repair & Fast CT2 Setup Patch
============================================================
Base version: v8.2.1
Type: changed-files patch / runtime repair / Fast CT2 setup
Date: 2026-05-19

Tujuan utama:
- Mencegah runtime Torch/Torchvision/Torchaudio rusak lagi karena pip memilih versi tidak cocok.
- Menyediakan repair script CUDA/CPU yang aman.
- Membuat Fast CT2 lebih jelas: ACTIVE vs FALLBACK_ARGOS, folder model, file yang kurang, dan kandidat folder.
- Menyiapkan Story Voice Hold untuk GFL2 voiced story agar teks yang bertahan saat voice berjalan tidak diproses berulang terlalu agresif.
- Menambahkan status OCR region agar crop terlalu besar bisa didiagnosa.

Cara pasang:
1. Tutup ORT/WebUI.
2. Extract ZIP patch.
3. Copy semua isi folder ORT_Translation_v8_3_CHANGED_FILES ke folder project ORT Anda.
4. Replace/Overwrite.
5. Jalankan Start_ORT_Translation.bat.

Catatan Fast CT2:
- Patch ini tidak membawa file model CT2 besar.
- Jika Fast CT2 masih FALLBACK_ARGOS, jalankan Runtime & Tools > Prepare Fast Engine Folder.
- Salin model CTranslate2 EN->ID ke models/ct2_opus_mt_en_id.
- Minimal dibutuhkan model.bin/model.bin.index.json dan source.spm + target.spm atau shared_vocabulary.json.

Catatan runtime GPU:
- Untuk RTX 4050, gunakan Repair_Torch_CUDA.bat jika EasyOCR/Torch rusak lagi.
- Validate_Runtime_GPU.bat dapat dipakai untuk memastikan torch.cuda.is_available() = True.

Known limitations:
- Fast CT2 belum bisa menjadi ACTIVE sampai model CT2 valid tersedia.
- Patch ini belum mengunduh/convert model otomatis.
- Audio Translate tetap roadmap v9, belum aktif.
