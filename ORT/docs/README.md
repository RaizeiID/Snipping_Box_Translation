## Tentang folder pendukung

Folder ORT menyimpan dokumentasi, alat pemeliharaan, manifest rilis, dan lokasi pendukung aplikasi. Isi runtime/log/cache lokal dapat berbeda antar instalasi.

Tiga launcher publik di folder utama adalah `Instalation First.bat`, `Start WebUI.bat`, dan `Repair Struktur ORT.bat`. Nama launcher atau instruksi patch pada catatan versi lama adalah dokumentasi historis; untuk pemasangan paket saat ini, ikuti README utama.

`Repair Struktur ORT.bat` digunakan untuk perbaikan atau migrasi struktur, bukan pengganti pemasangan pertama. Proses repair mempertahankan README utama di folder proyek.

Simpan cadangan data lokal sebelum menerapkan pembaruan. Environment Python, model, preferensi, log, dan data hasil pemakaian tidak perlu disertakan ketika mengunggah source.
