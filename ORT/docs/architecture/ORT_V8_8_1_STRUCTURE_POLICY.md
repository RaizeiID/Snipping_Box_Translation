# ORT v8.8.1 Structural Policy

v8.8.1 is intentionally limited to structural cleanup.

## Boundary

Allowed in v8.8.1:
- root cleanup;
- launcher UX;
- folder organization;
- docs/handoff update;
- .gitignore and GitHub-ready layout;
- compatibility bridge;
- version label update.

Not included in v8.8.1:
- Auto/Freeze/Interval behavior refactor;
- OCR policy change;
- translation model policy change;
- semantic gate change;
- cache namespace change.

This boundary keeps regression risk low before v8.8.2 behavior refactor.
