# Open Architecture Provider Metadata

This directory stores provider metadata, attribution, and future plugin manifests. Third-party runtime files and downloaded models belong in `ORT_Runtime/open_architecture`, not in this folder.

The current v9.0.0 release includes clean ORT adapters and architecture metadata only. It does not bundle LunaTranslator, Textractor, MORT, WhisperLive, SimulStreaming, WhisperStreaming, or Silero model weights.
